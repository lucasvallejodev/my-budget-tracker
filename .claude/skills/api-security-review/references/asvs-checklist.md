# ASVS checklist for CoinKeeper

> Summary: OWASP ASVS 4.0.3 requirements (Level 2 unless noted) mapped to concrete checks on CoinKeeper's files, with the expected result and the usual fix. Controls added in the hardening round (per-account throttle, session cap and rotation, JSON-only bodies, API CSP, redaction and audit events, proxy allow-list) are checks that they are not weakened; the remaining known gaps (email change without re-authentication, breached passwords, rehash) are written as checks to run, because they may have been fixed since.

IDs follow ASVS 4.0.3. ASVS 5.0 renumbered the chapters, so when you cite 5.0, look up its matching requirement instead of reusing the number. Severity guide: **blocker** means it can be exploited now or a control is weakened; **important** means a real gap that needs a condition or a second bug to exploit; **nit** means defense in depth or hygiene.

## 4. CSRF and origin (V4.2.2, V13.2.3)

- `rejectForeignOrigin` in `apps/api/src/plugins/security.ts` is unchanged: `SafeMethods` is still GET, HEAD and OPTIONS; the Origin comparison is exact membership in `ALLOWED_ORIGINS` plus `CORS_ORIGINS`; `Origin: null` is treated as absent; `Sec-Fetch-Site: cross-site` without an Origin is rejected.
- No GET handler changes state. A state-changing GET gets past both the origin check and SameSite=Lax (top-level navigation carries the cookie): **blocker**.
- JSON-only bodies. `registerSecurity` removes Fastify's default `text/plain` parser, so the API parses only `application/json`: `text/plain` (which an HTML form can send with `enctype="text/plain"`), `application/x-www-form-urlencoded` and `multipart/form-data` all answer `415 INVALID_REQUEST`, even on routes without a body schema (the `…/archive` and `…/restore` commands), before any handler runs. `app.test.ts` › request bodies pins it. Re-adding a `text/plain` parser, or any form or multipart parser, reopens the simple-request path for cross-site forms: **important**, or a **blocker** together with a weakened origin check. The origin check and `SameSite=Lax` stay the first defenses.
- Requests without Origin and without `Sec-Fetch-Site` (curl, scripts) pass the origin check by design. They still need a valid session.

## 6. Input, limits and injection (V5, V12, V13)

- **5.1.x** Every new route declares `params`, `querystring` and `body` from `packages/shared/src/schema/`. Strings have `.max()` from `FieldLengths`; enums come from `packages/shared/src/schema/enums.ts`; ids are UUID schemas (`idParamsSchema`).
- **5.1.4** Money arrives as strings and is parsed in `apps/api/src/routes/inputs.ts` (`parseAmount`, `parseMagnitude`). Floats and client-computed minor units are never accepted.
- **5.3.4** Only Drizzle builders or `sql` template tags. `sql.raw` with anything from the request is a **blocker**. Dynamic `ORDER BY` or column choice maps through a PascalCase lookup object of Drizzle columns, never string concatenation.
- **12.1.1, 13.1.x** `bodyLimit` stays at the Fastify default except `IMPORT_BODY_LIMIT` on imports. List endpoints cap `limit` at `MAX_PAGE_SIZE`. The CSV import keeps its size cap (`FieldLengths.importCsv` in `packages/shared/src/schema/imports.ts`).
- **5.2.x** No `eval`, `new Function`, `child_process` or template rendering of user input anywhere in `apps/api`.
- **10.x / SSRF** Check whether the change adds an outbound request (exchange rates are entered manually, so the API should make none). Any new outbound fetch, such as an FX rate provider, uses a fixed host from configuration, a timeout and no user-supplied URL.

## 7. Data exposure and errors (V7.4, V8, V13)

- **7.4.1** 5xx answers stay generic (`INTERNAL`, "Unexpected error"). The one deliberate exception is `503 UNAVAILABLE`: `plugins/error-handler.ts` answers any 503 with the fixed message "The service is temporarily unavailable", and readiness (`GET /api/v1/health/ready`) throws a `ServiceError` whose message is "The database is not reachable" and logs the driver error only at `warn`. Check that a new 503 path keeps a generic message and never carries the driver error or connection string (`plugins/error-handler.test.ts` pins the handler's behavior). `ServiceError` messages must not include SQL, stack traces, other users' data or internal ids the user does not own.
- **8.3.x** Response contracts never include `passwordHash`, `tokenHash` or `userId`. Routes return shared Zod contracts, never `$inferSelect` rows.
- **13.x** `/api/docs` stays off in production (`API_DOCS` unset with `NODE_ENV=production`).
- **8.3.x** `GET /me/sessions` shows IP and user agent only to the owner.

## 9. Client (V5.1.5, V5.3)

- **5.1.5 open redirect** `safeNextPath` (`apps/web/src/lib/navigation.ts`) resolves `next` with `URL.parse` against a placeholder origin and keeps it only when the result stays on that origin, so `//host`, `/\evil.example` (sent as `?next=%2F%5Cevil.example`, which browsers treat like a slash), encoded and absolute forms fall back to `/`; `navigation.test.ts` covers them. Check that every use of `next` goes through it and that the origin comparison was not replaced by a prefix check. A bypass is **important** (phishing after sign-in).
- **5.3.3** No `dangerouslySetInnerHTML`. User text (payee names, memos, category names) renders through React only.
- **5.3.x** Every CSV export builds its cells with `toCsvCell` from `packages/shared/src/lib/csv.ts`, which quotes each cell and prefixes text matching `Patterns.csvFormulaPrefix`; only plain decimals (`Patterns.decimalNumber`) skip the prefix. A new export path with its own escaping, or a looser `decimalNumber`, is **important** (CSV injection).
- `apiRequest` keeps `credentials: 'same-origin'` and relative `/api/v1` URLs. No absolute API URL is exposed to the browser.

## 10. Dependencies and supply chain (V14.2)

- **14.2.1** `npm audit --omit=dev --audit-level=high` shows no high or critical advisories in production dependencies. Report dev-only advisories as **nit** unless they run in CI with secrets.
- **14.2.4** A new runtime dependency is justified in the pull request (what it replaces, maintenance, install scripts). Prefer the existing stack: `@fastify/*` plugins, Zod, Drizzle.
- **14.2.x** Lockfile changes trace to `package.json` changes. An unexplained `resolved` host or integrity change is a **blocker** until it is explained.
- `quality.yml` runs `npm audit --omit=dev --audit-level=high` and `npm audit signatures` on every pull request; a change that removes or loosens them is **important**.
- CI hardening (SHA pins, `permissions:`, CodeQL, gitleaks, image scans) exists and belongs to `container-hardening`. Report a regression there, not a missing item.

## 11. Deployment coupling (V9, V14.1)

- `COOKIE_SECURE`: the production deployment must run with it true, behind HTTPS. `config.ts` makes it true when `NODE_ENV=production`, and `docker-compose.yml` passes `${COOKIE_SECURE:-true}`. An override or environment that sets it false for an internet deployment sends the session cookie over HTTP: **blocker**.
- `TRUST_PROXY` is `false` by default (`config.ts`, compose, `.env.example`) and otherwise a list of proxy addresses, CIDR ranges or `loopback`, `linklocal`, `uniquelocal`; `true` and hop counts are rejected at start-up (`TRUST_PROXY_ERROR`). Fastify then takes the right-most `X-Forwarded-For` entry that is not a listed proxy. Next.js forwards a client-sent `X-Forwarded-For` untouched, so the list is safe only when a proxy that replaces the header is the only way to reach `web`. A change that accepts `true` or hop counts again, changes the default, or a deployment that lists a range clients can connect from, lets a forged header change the rate-limit key: **important**, or a **blocker** when the change adds or relies on IP-based controls. The parser is owned by the fastify-api skill (`production.md` › Process-wide state and background work), the deployed value by `container-hardening`.
- `ALLOWED_ORIGINS` is the exact public origin; `CORS_ORIGINS` is empty unless a second web origin is intended.
- The API port stays unpublished, PostgreSQL stays bound to localhost and `web` to `${WEB_BIND_ADDRESS:-127.0.0.1}`.
