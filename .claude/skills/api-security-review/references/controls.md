# Existing controls

> Summary: every security control CoinKeeper relies on, named by file and symbol, with the test that pins it and the red flags that mean a change weakens it. Check these first in every review.

Symbols are named rather than line numbers, because line numbers drift. Find each one with `grep -n "<symbol>" <file>`. If a symbol has moved or been renamed, find where it went before you conclude it is gone.

## Limits

| Control       | Where                                                                                                                                                                | Guarantees                                                                                         |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| Body size     | Fastify default 1 MiB; `apps/api/src/routes/imports.ts`: `IMPORT_BODY_LIMIT` (`FieldLengths.importCsv` × 2) on the import routes                                     | Large bodies are rejected before parsing                                                           |
| Page size     | `packages/shared/src/constants/pagination.ts`: `MAX_PAGE_SIZE` (2000)                                                                                                | List endpoints cannot return unbounded rows                                                        |
| Field lengths | `packages/shared/src/constants/field-lengths.ts`: `FieldLengths` used by the Zod contracts                                                                           | Every string input has a maximum                                                                   |
| Id lists      | `packages/shared/src/schema/common.ts`: `orderSchema` (`MAX_ORDERED_IDS` 1000, `hasDistinctItems`)                                                                   | Reorders take a bounded list of distinct ids                                                       |
| Time          | `config.ts`: `HANDLER_TIMEOUT_MS` (20 s) as Fastify `handlerTimeout`; `constants/http.ts`: `ServerTimeoutsMs`; `db/index.ts`: `statement_timeout` one second shorter | A slow request or query ends with `503` instead of holding a connection (`app.test.ts` › timeouts) |

Red flags: a raised `bodyLimit` without a reason; a list endpoint without `limit` capped by `MAX_PAGE_SIZE`; a string schema without `.max()`; an array input without `.max()`; a timeout set to `0` or raised globally for one slow route.
