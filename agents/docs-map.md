## Document → what it covers

| Document                                | Covers                                                                                                                                                                  |
| --------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `docs/README.md`                        | product pitch, doc organisation, quick start                                                                                                                            |
| `docs/getting-started/*`                | setup, commands, folder structure                                                                                                                                       |
| `docs/architecture/overview.md`         | workspaces, browser → Next.js rewrite → Fastify → services → PostgreSQL flow, principles, rule enforcement table                                                        |
| `docs/architecture/data-model.md`       | tables (users and sessions included), relationships (mermaid), invariants, soft deletes                                                                                 |
| `docs/architecture/money.md`            | minor units, parsing, formatting, currency rules, FX provider                                                                                                           |
| `docs/architecture/api.md`              | Fastify layout, request lifecycle, sessions and cookie, access layers, errors, soft deletes, config, adding an endpoint                                                 |
| `docs/reference/rest-api.md`            | every REST endpoint with its parameters and responses                                                                                                                   |
| `docs/architecture/server.md`           | domain services in `apps/api/src/modules/`: wiring, conventions, `ServiceError`, soft deletes, bootstrap at sign-up, adding a method                                    |
| `docs/architecture/frontend.md`         | screens, API client, hooks, mutations, auth pages and route guard, user menu, settings security, deleted items, `useHydrated`, forms, pickers, styling, adding a screen |
| `docs/architecture/components.md`       | component modules and folders, BEM, cascade layers, breakpoints, mixins, `ui` catalogue                                                                                 |
| `docs/architecture/testing.md`          | test kinds and Vitest projects, API route and service tests on PGlite, component tests mocking `@/api/mutations`, coverage expectations                                 |
| `docs/architecture/code-style.md`       | formatting, naming, constants and colours, complexity budget, lint tooling                                                                                              |
| `docs/features/*.md`                    | one page per feature: steps, statuses, "How it works"                                                                                                                   |
| `docs/features/account-and-security.md` | sign-up, sign-in and out, profile, password, sessions, operator password reset                                                                                          |
| `docs/features/deleted-items.md`        | soft delete, Undo toast, the Deleted items screen, restore rules                                                                                                        |
| `docs/reference/*.md`                   | REST endpoints, migrations (and resetting an old local database), default taxonomy                                                                                      |
| `docs/legacy/*`                         | frozen history; never update, only add                                                                                                                                  |
| `agents/*.md`                           | condensed versions for agents; keep in sync with the above                                                                                                              |
| `README.md`                             | repository layout, setup, commands, docs pointers                                                                                                                       |
| `CLAUDE.md` / `AGENTS.md`               | agent operating rules                                                                                                                                                   |
